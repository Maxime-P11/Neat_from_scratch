# Neat_from_scratch
implementation of the Neat Algorithm

fr : 
Ceci est une implémentation du l’algorithme NEAT (Neuro Evolution of Augmented Topologies)<br/>
test_XOR est un ficher pour tester Neat sur le problème XOR<br/>
NEAT : c'est la version standard la plus rapide, elle n'utilise pas les espèces pour une question de vitesse, je recommande 2000 générations<br/>
NEAT_species : implémente les espèces mais est lent, je recommande 500 - 1000 générations<br/>

en :
This is an implementation of the NEAT (Neuro Evolution of Augmented Topologies) algorithm<br/>
test_XOR is a file to test NEAT on the XOR logic gate<br/>
NEAT : this is the default version, it doesn't implement species for performence result, I recommand running XOR for 2000 generations<br/>
NEAT_species : implement species but it very slow, I recommand running XOR for 500 - 1000 generations<br/>
