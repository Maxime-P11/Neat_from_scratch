# Neat_from_scratch
implementation of the Neat Algorithm

fr : 
Ceci est une implémentation du l’algorithme NEAT (Neuro Evolution of Augmented Topologies)
test_XOR est un ficher pour tester Neat sur le problème XOR
NEAT : c'est la version standard la plus rapide, elle n'utilise pas les espèces pour une question de vitesse, je recommande 2000 générations
NEAT_species : implémente les espèces mais est lent, je recommande 500 - 1000 générations

en :
This is an implementation of the NEAT (Neuro Evolution of Augmented Topologies) algorithm
test_XOR is a file to test NEAT on the XOR logic gate
NEAT : this is the default version, it doesn't implement species for performence result, I recommand running XOR for 2000 generations
NEAT_species : implement species but it very slow, I recommand running XOR for 500 - 1000 generations
